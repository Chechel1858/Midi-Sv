Плата MIDI Analog Filter: куда что подключать

Схемы нарисованы по фото платы, в той же ориентации: фильтр сверху, MIDI и процессор снизу, DIN-разъёмы и USB справа. На каждой схеме жёлтым подсвечено только то, что нужно для этого шага. Подробности и команды — в README репозитория.

Обзор платы

Три зоны: сверху аналоговый фильтр (стерео, L и R), посередине питание (из USB делаются ±15 В), снизу MIDI, процессор STM32F446 и выходы управляющих напряжений.

Первая прошивка через ST-Link

Нужна один раз: заливает загрузчик и прошивку вместе. Дальше обновления идут по USB.

Порядок

  1. Впаяй 4-пиновую гребёнку в первые 4 отверстия SWD (J13). Если там уже стоит разъём — паять не надо.
  2. Воткни USB-B в компьютер. Найди пин 1: на нём 3.3 В. Пин 3 звонится с корпусом USB-разъёма — это земля.
  3. Провода: SWCLK → 2, GND → 3, SWDIO → 4.
  4. STM32CubeProgrammer → ST-LINK, SWD → Connect → файл midi_cv_full.hex → Start Programming.

USB: работа и обновление прошивки

Один и тот же кабель. Разница только в том, держишь ли ты LEARN в момент подключения.

Обновить прошивку

  1. Зажми LEARN, воткни USB, отпусти. Или набери dfu в COM-порту.
  2. dfu-util -a 0 -D midi_cv_alpha.dfu
  3. Через полторы секунды плата сама запустит новую прошивку. Передумал — коротко нажми LEARN.

MIDI

Обычный 5-пиновый MIDI-кабель. Вместо клавиатуры можно играть из компьютера по USB — плата принимает оба входа сразу.

Что важно

  • IN — нижний разъём, THRU — верхний.
  • THRU работает аппаратно, даже если процессор не прошит.
  • Всё, что пришло в DIN IN, плата пересылает в компьютер по USB — её можно использовать как MIDI-интерфейс.
  • Разъёма MIDI OUT на этой плате нет.

CV, GATE и CLOCK

Выходы — площадки на плате. Припаяй к ним провода или штырьки. Землю для синта возьми с пина 3 разъёма SWD.

Проверка мультиметром

  • set jack 5000 → на J1 около 5 В
  • gate on → на J14 около 5 В

J31 — это голая ножка процессора: 3.3 В и инверсная логика (под будущий транзисторный каскад). Подключай только к входам, которые терпят 3.3 В и не подают напряжение обратно.

Фильтр и аудио

Верхняя половина — стерео аналоговый фильтр. Срез управляется ручкой FILTER, процессором (CC74 по умолчанию) и внешним CV — всё складывается.

  • Распиновку белых разъёмов проверь прозвонкой: земляной контакт звонится с землёй (пин 3 SWD).
  • Подстроечные резисторы выставлены при сборке — крути их, только если знаешь, что настраиваешь.

Кнопка LEARN и светодиод NOTEON

Что произойдёт, зависит от того, сколько держать кнопку. Отсчёт идёт с момента нажатия.

Запасная консоль USART1

Нужна, только если USB не завёлся. Понадобится отдельный USB-UART переходник на 3.3 В — ST-Link так не умеет.

  • Разъём J22 — три пина: TX, RX, GND. Порядок проверь прозвонкой: GND звонится с пином 3 SWD.
  • В терминале: 115200 бод, 8N1. Команды те же, что в COM-порту по USB.
