# SysEx: настройка платы по MIDI

Всё, что настраивается командой `p` в COM-порту, можно менять и MIDI-сообщениями SysEx — по USB
или через DIN MIDI IN. Формат взят из ТЗ MIDI-CV/Gate rev 1.1, раздел 20.

## Формат

```
F0 7D 4D <dev> <cmd> <param> <len> <data...> <crc7> F7
```

| Байт | Значение |
|---|---|
| `7D` | development manufacturer ID (пока нет своего MIDI Manufacturer ID) |
| `4D` | код изделия («M») |
| `dev` | номер устройства: `00`, или `7F` — «всем» |
| `cmd` | команда (таблица ниже) |
| `param` | номер параметра |
| `len` | число байт данных: `0` или `3` |
| `data` | значение: 21-битное число со знаком, по 7 бит, старшие первыми |
| `crc7` | CRC-7/MMC (полином x⁷+x³+1, начальное 0) по байтам от `4D` до последнего байта данных |

Значение `v` → 3 байта: `(v >> 14) & 7F`, `(v >> 7) & 7F`, `v & 7F` (для отрицательных берётся
дополнительный код в 21 бит). Например, 5000 → `00 27 08`, −2500 → `7F 6C 3C`.

Ответ приходит туда же, откуда пришёл запрос (USB или DIN), в том же формате.

## Команды

| cmd | Команда | Что делает | Ответ |
|---|---|---|---|
| `01` | GET | прочитать параметр `param` | VALUE |
| `02` | SET | записать `data` в параметр (сразу применяется, в RAM) | ACK / NACK |
| `03` | SAVE | сохранить текущие настройки во флеш | ACK / NACK |
| `04` | DUMP | все параметры | VALUE × N, затем ACK |
| `05` | FACTORY RESET | заводские настройки (в RAM; SAVE — чтобы сохранить) | ACK |
| `06` | CAL UNLOCK | `data` = `43 41 4C` («CAL») — разрешить калибровку до перезагрузки | ACK / NACK |
| `07` | CAL SET | как SET, для калибровочных параметров | ACK / NACK |
| `08` | DIAG | версия, чип, кварц, счётчики | VALUE × 6, затем ACK |

Ответы: `41` VALUE (`param` + значение), `7E` ACK (`param` = номер команды),
`7F` NACK (`param` = номер команды, значение = код ошибки).

| Код ошибки | Причина |
|---|---|
| 1 | неверная CRC |
| 2 | неизвестная команда |
| 3 | неизвестный параметр |
| 4 | значение вне диапазона |
| 5 | калибровка закрыта (сначала CAL UNLOCK) |
| 6 | неверная длина |
| 7 | ошибка записи во флеш |

На alpha-плате нет перемычки SERVICE из ТЗ, поэтому калибровку открывает команда CAL UNLOCK
с ключом «CAL»; после перезагрузки она снова закрыта.

## Параметры

| id | Имя (`p` в консоли) | Диапазон | Что это |
|---|---|---|---|
| 1 | channel | 0…16 | MIDI-канал, 0 = omni |
| 2 | zero | 0…127 | нота, дающая 0 В |
| 3 | bend | 0…24 | диапазон pitch bend, полутоны |
| 4 | retrig | 0/1 | провал GATE на легато |
| 5 | clockdiv | 1…96 | MIDI Clock на импульс CLOCK |
| 6 | clockpulse | 1…50 | длина импульса CLOCK, мс |
| 7 | gateinv | 0/1 | инверсия GATE |
| 10 / 20 | jack.src / filter.src | 0…5 | источник: 0 off, 1 pitch, 2 vel, 3 cc, 4 aftertouch, 5 bend |
| 11 / 21 | jack.cc / filter.cc | 0…127 | номер CC |
| 12 / 22 | jack.smooth / filter.smooth | 0…100 | сглаживание, мс |
| 13 / 23 | jack.range / filter.range | 100…10500 | напряжение при 127, мВ |
| 14 / 24 | jack.cal0 / filter.cal0 | −2000…2000 | калибровка: код ЦАП при 0 В (нужен CAL UNLOCK) |
| 15 / 25 | jack.gain / filter.gain | 20000…65000 | калибровка: кодов на вольт ×100 (нужен CAL UNLOCK) |
| 30 | attack | 0…10000 | огибающая фильтра: атака, мс |
| 31 | decay | 0…10000 | спад, мс |
| 32 | sustain | 0…127 | уровень удержания |
| 33 | release | 0…10000 | затухание, мс |
| 34 | env | −10000…10000 | глубина огибающей, мВ (минус — закрывает фильтр) |
| 35 | envvel | 0…100 | влияние velocity на глубину, % |
| 36 | envretrig | 0/1 | перезапуск огибающей на легато |
| 40 | lfoshape | 0…5 | 0 sine, 1 tri, 2 square, 3 saw up, 4 saw down, 5 random |
| 41 | lforate | 1…3000 | частота LFO, Гц ×100 (200 = 2 Гц) |
| 42 | lfo | 0…10000 | глубина LFO, мВ |
| 43 | lfosync | 0/1 | LFO с начала на каждой ноте |
| 44 | lfowheel | 0/1 | колесо модуляции (CC1) управляет глубиной LFO |
| 45 | keytrack | 0…100 | фильтр следует за нотой, % от 1 В/окт |
| 50 | glide | 0…10000 | портаменто, мс (0 = выкл) |
| 51 | glidemode | 0/1 | 0 = мс на октаву (constant rate), 1 = мс на весь переход (constant time) |
| 52 | glidelegato | 0/1 | 1 = только легато, 0 = всегда |

Только для чтения (в ответах DUMP / DIAG): `00` версия протокола (1), `70` версия прошивки
(200 = 0.2.0), `71` ID чипа (`0x411` = F2, `0x421` = F446), `72` частота кварца, МГц,
`73` принято MIDI-сообщений, `74` ошибок DIN, `75` причина последнего сброса (RCC CSR >> 24).

## Примеры

| Что | Байты |
|---|---|
| прочитать канал | `F0 7D 4D 00 01 01 00 22 F7` |
| глубина огибающей = 5000 мВ | `F0 7D 4D 00 02 22 03 00 27 08 6C F7` |
| глубина огибающей = −2500 мВ | `F0 7D 4D 00 02 22 03 7F 6C 3C 6D F7` |
| форма LFO = треугольник | `F0 7D 4D 00 02 28 03 00 00 01 29 F7` |
| портаменто 200 мс | `F0 7D 4D 00 02 32 03 00 01 48 16 F7` |
| сохранить | `F0 7D 4D 00 03 00 00 77 F7` |
| все параметры | `F0 7D 4D 00 04 00 00 33 F7` |
| диагностика | `F0 7D 4D 00 08 00 00 6C F7` |

Любое другое сообщение соберёт `firmware/tools/mcv_sysex.py`:

```
python firmware/tools/mcv_sysex.py set lforate 350
python firmware/tools/mcv_sysex.py --send dump      # отправить на плату (нужны: pip install mido python-rtmidi)
python firmware/tools/mcv_sysex.py decode "F0 7D 4D 00 41 22 03 00 27 08 xx F7"
```
