# Плата MIDI Analog Filter alpha — что где (по схеме)

Источник: `MIDI_Analog_Filter_alpha_SCH.pdf` (2 листа: аналоговый фильтр и цифровая часть).

## Микроконтроллер DD1

На плате стоит **STM32F205RBT6**, как подписано на схеме (проверено: Device ID 0x411, 128 КБ флеша,
Cortex-M3, кварц 8 МГц). Пометка на схеме «Если 205/405, то Vcap; если 446, то 0 Ом» — про замену
чипа: у F446 в LQFP64 ножка 47 — это VSS, и вместо конденсатора там нужна перемычка 0 Ом.

Прошивка работает на любом из трёх (F205RB, F405RG, F446RE):

- собрана под Cortex-M3 (F205 — M3, F405/F446 — M4F, код M3 на них тоже выполняется);
- загрузчик 32 КБ + настройки 16 КБ + прошивка 80 КБ — влезает даже в F205RB (128 КБ), см. «Карта памяти»;
- ОЗУ 64 КБ — минимальное из трёх;
- тактирование 120 МГц (максимум F205), USB 48 МГц — одинаково на всех;
- частота кварца Y1 на схеме не указана, поэтому прошивка **измеряет её сама** при старте
  (TIM11 умеет ловить HSE/RTCPRE, отсчёт ведётся от внутреннего RC 16 МГц). Поддерживаются
  кварцы 4…26 МГц. Если кварца нет — работа от внутреннего RC (USB тогда может глючить).

## Карта памяти

| Адрес | Секторы | Что |
|---|---|---|
| 0x08000000 | 0–1 (32 КБ) | USB DFU загрузчик (`firmware/bootloader`) |
| 0x08008000 | 2 (16 КБ) | настройки (с CRC) |
| 0x0800C000 | 3–4 (80 КБ) | основная прошивка; на F446RE можно расширить до 0x08080000 |
| 0x2000FFF0 | 16 байт ОЗУ | флаг «останься в DFU», который прошивка оставляет перед перезагрузкой |

Встроенный ROM-загрузчик STM32 по USB на этой плате не работает (он умеет только PA11/PA12),
поэтому свой загрузчик работает с тем же ядром OTG_HS на PB14/PB15, что и основная прошивка.
Протокол — стандартный DFU 1.1 (`dfu-util`), VID:PID 1209:0002 (у основной прошивки 1209:0001;
это тестовые PID с pid.codes, для серийного устройства нужен свой VID/PID). Для Windows
отдаются дескрипторы Microsoft OS 2.0, поэтому драйвер WinUSB ставится сам.

## Питание

Всё от **USB VBUS** (разъём USB-B J40): LDO U4 → +3.3 В (цифра), повышающий DC/DC U7 → ±17 В →
стабилизаторы 78L15/79L15 (U6/U5) → ±15 В для ОУ и фильтра. В USB-дескрипторе запрошено 500 мА.

## Аналоговые выходы — расчёт

- DAC STM32: 12 бит, 0…3.3 В (VREF+ = VDDA), выходной буфер DAC **выключен** — он нагружен
  только на вход ОУ, а без буфера выход честно доходит до 0 В.
- Усиление: 1 + R1/R2 = 1 + 68k/33k = **3.0606** → 0…10.10 В.
- 405.45 кода на вольт, 2.47 мВ на код. Полутон при 1 В/окт = 83.3 мВ ≈ 34 кода,
  шаг ≈ 3 цента — для прототипа достаточно; для точного pitch в ТЗ стоит 16-битный DAC80502.
- Коэффициенты по умолчанию номинальные; реальные задаются калибровкой (`cal`), хранятся во флеше.

## Замечания к схеме (стоит проверить на плате)

1. **GATE при включении.** Пока процессор не стартовал, PA6 висит, R70 тянет затвор Q18 к
   земле, MOSFET закрыт, и GATE_OUT подтянут к +5 В — то есть **gate «включён»** на время
   сброса. Прошивка первым делом ставит PA6 = 1 (gate выключен), это доли миллисекунды после
   старта, но при прошивке/зависании на выходе будут 5 В. Если это мешает — подтяжку R70
   стоит перенести на +3.3 В (или поменять логику каскада).
2. **USB на PB14/PB15** (ядро OTG_HS), а не на PA11/PA12. Из-за этого встроенный загрузчик
   STM32 (DFU) по USB на этой плате работать не будет — он умеет только OTG_FS на PA11/PA12.
   Прошивать — только через SWD (ST-Link).
3. **VBUS не заведён на процессор** (PB13 не подключён), прошивка отключает VBUS-sensing
   в USB-ядре (на F205/F405 и F446 это разные биты — учтено).
4. Разъёма MIDI OUT нет, USART2_TX выведен только на J19.
5. CLOCK_3v3 подписан с инверсией, но выведен только на тестпоинт J31 — видимо, под будущий
   транзисторный каскад как у GATE. Прошивка уже выдаёт его активным низким.
6. Светодиоды D1/D2 помечены «не паять» — если NOTEON не горит, проверь, запаян ли D1.

## Отличия от ТЗ MIDI-CV/Gate rev 1.1

ТЗ описывает следующее устройство. На alpha-плате:

| ТЗ rev 1.1 | Alpha-плата |
|---|---|
| STM32F446RET6 | STM32F205RBT6 |
| DAC80502 16 бит (Pitch, CV4) + 2× DAC STM32 (CV2, CV3) | только 2× DAC STM32 12 бит: выход CV (J1) и срез фильтра |
| Pitch −3…+8 В | 0…+10 В (однополярный каскад) |
| NOTE GATE + GATE1…4 (PC4, PC0…PC3) | один GATE на PA6 |
| CLOCK + START/STOP/CONTINUE/RUN/RESET | CLOCK на тестпоинте J31 |
| EEPROM 24C512 (I²C PB6/PB7) | нет, настройки во внутреннем флеше (PB6/PB7 — тестпоинты) |
| USB на PA11/PA12 (OTG_FS) | USB на PB14/PB15 (OTG_HS + встроенный FS PHY) |
| LEARN на PB0 | LEARN на PC3 |
| SysEx-конфигурация | текстовая консоль по USB COM-порту |

Логика, которая уже сделана по ТЗ: Last Note Priority со стеком, Note On vel=0 = Note Off,
повтор той же ноты не роняет gate, CC64 Sustain, pitch bend 14 бит с насыщением, Zero Volt Note
(по умолчанию 36), сглаживание AUX CV, Channel Learn (3 с удержания, 10 с таймаут, повторное
нажатие — отмена, Omni отдельным долгим удержанием), merge DIN+USB с общим состоянием нот,
делители клока /1…/96, настройки с CRC.
